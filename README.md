# Відлік до Wardogs

Сайт-таймер зворотного відліку до виходу [WARDOGS](https://store.steampowered.com/app/1867240/WARDOGS/)
(BULKHEAD / Team17) у Steam Early Access.

**Живий сайт:** https://elgias.github.io/wardogs-countdown/

## Що всередині

Статична сторінка без збірки і без зовнішніх запитів. Уся розмітка, CSS, JS
і графіка фону лежать в `index.html`. Шрифти локальні.

| Файл | Призначення |
|---|---|
| `index.html` | вся сторінка |
| `fonts.css` + `fonts/` | локальні шрифти (7 файлів woff2, 160 КБ) |
| `scripts/selfhost-fonts.mjs` | перезбирає `fonts.css` і `fonts/` з Google Fonts |
| `favicon.svg` | іконка вкладки |
| `og.png` | картинка для превʼю посилання (1200×630) |

## Дата релізу

Ціль зашита в `index.html` одним рядком:

```js
var TARGET = Date.UTC(2026, 8, 10, 17, 0, 0);
```

У `Date.UTC` місяці рахуються з нуля, тому `8` — це вересень.

Реліз: **10 вересня 2026, 17:00 UTC**. Дату підтверджує сторінка в Steam.
Час взято з розкладу власника сайту; частина ЗМІ (Game8) раніше писала про 16:00 UTC,
а Steam офіційно години не називав. Тому в підвалі стоїть рядок «час може змінитися».

Сторінка показує цей момент ще й у часовому поясі відвідувача — обчислюється в браузері,
нічого налаштовувати не треба.

## Шрифти

Сторінка **не звертається до `fonts.googleapis.com`**. Браузери з посиленим захистом
приватності (Zen, Firefox у строгому режимі, uBlock) блокують цей домен, і тоді всі
накреслення мовчки падають на системні — сторінка виглядає зовсім інакше, без жодної помилки.
Тому Anton, IBM Plex Sans і IBM Plex Mono лежать у репозиторії.

Взято тільки підмножини `latin` і `cyrillic`: українська повністю вкладається в `cyrillic`
(діапазон U+0400–045F плюс U+0490–0491 для ґ). IBM Plex Sans віддається як варіативний шрифт,
тому три накреслення 400/500/600 — це один файл із діапазоном ваг.

Оновити шрифти:

```bash
node scripts/selfhost-fonts.mjs
```

## Локальний запуск

Просто відкрийте `index.html` у браузері. Сервер не потрібен.
