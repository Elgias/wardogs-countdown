# Відлік до Wardogs

Сайт-таймер зворотного відліку до виходу [WARDOGS](https://store.steampowered.com/app/1867240/WARDOGS/)
(BULKHEAD / Team17) у Steam Early Access.

**Живий сайт:** https://elgias.github.io/wardogs-countdown/

## Що всередині

Статична сторінка без збірки і без зовнішніх запитів. Уся розмітка, CSS, JS
і графіка фону лежать в `index.html`. Шрифти локальні.

| Файл | Призначення |
|---|---|
| `index.html` | вся сторінка |
| `embed.html` | компактна версія для вбудовування в iframe |
| `check.html` | діагностика шрифтів у браузері читача |
| `fonts.css` + `fonts/` | локальні шрифти (7 файлів woff2, 160 КБ) |
| `scripts/selfhost-fonts.mjs` | перезбирає `fonts.css` і `fonts/` з Google Fonts |
| `favicon.svg` | іконка вкладки |
| `og.png` | картинка для превʼю посилання (1200×630) |

## Дата релізу

Ціль зашита **у двох файлах** — `index.html` і `embed.html`. Міняйте обидва разом,
інакше повна сторінка і ембед покажуть різний час:

```js
var TARGET = Date.UTC(2026, 8, 10, 16, 0, 0);
```

У `Date.UTC` місяці рахуються з нуля, тому `8` — це вересень.
Час також написаний текстом у `.aim` (index), `.tgt` (embed), в `og:description`
і на картинці `og.png`.

Реліз: **10 вересня 2026, 16:00 UTC**. Дату підтверджує сторінка в Steam, час — Game8.
7 вересня сайт короткий час показував 17:00 UTC (за годиною відкриття закритих тестів);
10 вересня повернули 16:00. Steam офіційно години не називав, тому в підвалі стоїть
рядок «час може змінитися».

Сторінка показує цей момент ще й у часовому поясі відвідувача — обчислюється в браузері,
нічого налаштовувати не треба.

## Вбудовування

`embed.html` — та сама ціль і той самий відлік, але без карти, бокових рейок,
годинників, шкали днів і джерел. Лишились назва гри, таймер і прогрес.

```html
<iframe src="https://elgias.github.io/wardogs-countdown/embed.html"
        width="100%" height="200" frameborder="0" scrolling="no"
        title="Відлік до Wardogs"></iframe>
```

Розміри всередині рахуються як `min()` від ширини **і** висоти вікна, тому сторінка
підлаштовується під будь-яку рамку, а не тільки під широку. Коли висоти бракує,
зайві рядки зникають за пріоритетом:

| Висота рамки | Що зникає |
|---|---|
| менше 170 px | підписи `ДНІВ / ГОД / ХВ / СЕК` |
| менше 132 px | рядок з датою релізу і відсотком |
| менше 104 px | підзаголовок біля назви |

Назва, відлік і смуга прогресу не зникають ніколи. Мінімальна робоча рамка —
приблизно 260×90 px. Прогрес — це одна суцільна смуга, а не сім блоків по днях,
як на головній: блоки потребують підпису кожен і у вузькій рамці перетворюються на риски.

## Шрифти

Сторінка **не звертається до `fonts.googleapis.com`**. Браузери з посиленим захистом
приватності (Zen, Firefox у строгому режимі, uBlock) блокують цей домен, і тоді всі
накреслення мовчки падають на системні — сторінка виглядає зовсім інакше, без жодної помилки.
Тому Anton, IBM Plex Sans і IBM Plex Mono лежать у репозиторії.

Взято тільки підмножини `latin` і `cyrillic`: українська повністю вкладається в `cyrillic`
(діапазон U+0400–045F плюс U+0490–0491 для ґ). IBM Plex Sans віддається як варіативний шрифт,
тому три накреслення 400/500/600 — це один файл із діапазоном ваг.

Оновити шрифти:

```bash
node scripts/selfhost-fonts.mjs
```

## Локальний запуск

Просто відкрийте `index.html` у браузері. Сервер не потрібен.
